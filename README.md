# Blowtown

Een rustig isometrisch bouwspel in de browser, zonder geld, levels of wachttijden: alles is altijd beschikbaar.

- `index.html` – het hele spel (HTML, CSS en JavaScript in één bestand)
- `assets/tiles/` – grondtegels, wegen, water, spoor, flats, auto's, mensen, versieringen (Kenney.nl, CC0, plus eigen tekeningen)
- `assets/gebouwen/` – gebouwen (Cozy Isometric Town van Laninya, aangepaste varianten)
- `assets/boerderij/` – boerderijonderdelen (Guilherme Laso, vrij te gebruiken)
- `assets/*.json` – per sprite de bestandsnaam, afmetingen en het ankerpunt op het raster

Dorpen worden bewaard in de browser (localStorage). Hosting: Netlify, geen build-stap nodig.

Graphics: Kenney (kenney.nl, CC0), Laninya (itch.io, Cozy Isometric Town), Guilherme Laso (itch.io, Farm isometric assets).
